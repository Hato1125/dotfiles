# コミット

## リポジトリの指定

commit-message スキルと同じ。

## 流れ

1. commit-message スキルを読み、その基準で対象の変更・コミット単位・メッセージを決める。
2. 分割になるなら、分割か一括かを選択ダイアログで聞く。一括になるなら聞かずに進める。
3. 決めた単位ごとに、対象の差分だけをステージしてコミットする。
   部分ステージが必要なら、該当箇所だけをステージする。
4. コミットごとにハッシュと件名を報告する。失敗した場合は、どこまで進んだかを伝える。

## 制限

- push しない。
- 対象外の差分をステージしない。ファイルの内容も変更しない。
- コミットできないリポジトリがあっても、他の対象は続ける。
